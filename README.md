# 算法题刷题记录

本项目主要用于记录和整理算法题的解答，主要涵盖以下两个平台：

- [LeetCode 热门 100 题](https://leetcode.cn/studyplan/top-100-liked/)
- [CodeTop](https://codetop.cc/home)

## 项目结构

```
├── src/
│   ├── hot100/           # LeetCode 热门 100 题解答
│   │   ├── array/        # 数组相关题目
│   │   ├── back_tracking/ # 回溯算法
│   │   ├── double_pointer/ # 双指针
│   │   ├── dp/           # 动态规划
│   │   ├── greedy/       # 贪心算法
│   │   ├── hash/         # 哈希表
│   │   ├── heap/         # 堆
│   │   ├── linklisted/   # 链表
│   │   ├── map/          # 映射
│   │   ├── matrix/       # 矩阵
│   │   ├── mult_dp/      # 多重动态规划
│   │   ├── select/       # 选择问题
│   │   ├── skill/        # 技巧类题目
│   │   ├── sliding_window/ # 滑动窗口
│   │   ├── stack/        # 栈
│   │   ├── sub_string/   # 子串问题
│   │   └── tree/         # 树相关题目
│   └── codetop/          # CodeTop 题目解答
│       └── page01/       # 按页面分类的题目
```
